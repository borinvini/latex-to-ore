## Files to submit
- [ ] manuscript.docx — the article (figures REMOVED, only legends at end; tables after references)
- [ ] figures/Figure1..N — one file per cited figure, TIFF or JPEG, 300 dpi colour / 600 dpi greyscale
- [ ] data deposit — all underlying data in an approved repository (figshare/Zenodo) under CC BY or CC0, with a DOI (see data-package-structure.md)

## Manuscript content (in manuscript.docx)
- [ ] Title — concise, specific
- [ ] Authors — affiliations listed; affiliation superscripts match the number of affiliations
- [ ] Corresponding author details — placed AFTER the affiliations
- [ ] Structured abstract — Background/Methods/Results/Conclusions, no citations, <=300 words (email said 350; 300 is safe), accurately reflects the manuscript
- [ ] Keywords — up to 8
- [ ] Plain Language Summary — recommended, optional
- [ ] Main body — Introduction / Methods / Results / Conclusions-Discussion, <=15,000 words
- [ ] Preprint self-citation — cite the ORE preprint version of THIS article (add once preprint DOI is known)
- [ ] References — consistent style; URLs as in-text hyperlinks

## Declarations (at the END, before references, in this order)
- [ ] Data Availability — MANDATORY; "Underlying data" (Repository name: [title]. https://doi.org/XXXX. + bulleted file list) and "Extended data" ("There is no extended data associated with this article." if none); ends with the license sentence (CC BY 4.0 or CC0)
- [ ] Ethics and consent — immediately after Data Availability; ethics board name + approval number + consent type, OR "Ethical approval and consent were not required."
- [ ] Competing Interests — MANDATORY ("No competing interests were disclosed" if none)
- [ ] Grant Information — every funder (name, grant number, grantee); MUST match all funders declared in the submission-system FundRef/funding form
- [ ] Acknowledgments — optional, no grant funding here

## Figures & tables (ORE placement rules)
- [ ] Figures removed from body; only legends remain, collected at end of manuscript (auto-done at conversion, Phase 5)
- [ ] Every CITED figure is actually provided (no "Figure N cited but missing"); no supplied figure is uncited
- [ ] Figure files are TIFF or JPEG, 300 dpi colour / 600 dpi greyscale (re-export from source as needed)
- [ ] Tables + their legends placed AFTER the references section, not in-between body text
- [ ] Every figure and every table has a legend
